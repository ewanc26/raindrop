# Support

raindrop is an early, pre-release project — expect change and rough edges,
please.

- **Bugs and design feedback:** [open an issue](https://github.com/ewanc26/raindrop/issues)
  (a template will guide you).
- **General questions:** ask Ewan on Bluesky at
  [@ewancroft.uk](https://bsky.app/profile/ewancroft.uk).
- **Security:** see [SECURITY.md](SECURITY.md) — never a public issue.
- **Keeping the lights on:** raindrop is free and open source;
  [support the project's maintainer](https://ewancroft.uk/support).

There is no warranty, formal support channel, or build distribution yet; when
tagged releases appear this page will say where to report issues per version.
