# Contributing

Thank you for wanting to help, please note that raindrop is at the design stage,
so the most valuable contributions right now are design feedback, issue triage,
and build/CI knowledge, not yet large code changes.

## Ways to help

- Read [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) and open issues challenging
  any part of the trust and failure model.
- Report concrete upstream knowledge: patch surface for custom schemes, minimal
  build configs, or CI lessons from other Firefox forks.
- Pick up a Phase 0 checklist item from the [roadmap](docs/ROADMAP.md).

## Ground rules

- Discuss designs in issues before large PRs.
- Keep patches in the isolated `atproto/` module where possible; anything that
  touches stock Firefox code should be flagged in the PR description.
- Be kind. This project builds on open protocol work; treat everyone the way the
  Atmosphere community treats newcomers.
